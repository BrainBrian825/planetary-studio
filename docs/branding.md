# Planetary Studio logo

The original transparent PNG is [planetary-studio.png](../src/planetary_studio/assets/planetary-studio.png). The same image is packaged as macOS ICNS and Windows ICO icons and used inside the desktop app.

Created with the built-in image generation tool. Only resizing and native icon format export are performed by `packaging/create_icons.py`; the generated design is preserved.

## Final prompt

Use case: logo-brand. Asset type: desktop app logo and Dock icon for Planetary Studio, a planetary astronomy capture and image processing application. Create a single polished square 1024 by 1024 app icon. Minimal, calm, monochrome visual identity: a solid charcoal rounded square tile, centered clean silver-white ringed planet symbol, one small four-point star above the ring. Simple bold silhouette that remains legible at 32 pixels, generous padding, balanced proportions. Flat vector-like geometry with very subtle satin depth only. No letters, no words, no text, no colorful glow, no nebula, no busy background, no mockup, no device frame. Transparent outside the rounded square tile. This is the actual finished logo asset, not a sheet of alternatives.
